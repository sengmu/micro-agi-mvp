Micro-AGI MVP 是一个基于 Termux 的手机本地智能体控制中心。内置 Live2D 交互、独立的 AI 技能商店与 MCP 工具端点，支持离线语音唤醒，全屏运行于独立的 Android WebView 容器中。

Powerful Features

为本地智能体打造的完整生态

🌸

Live2D 虚拟助手 (Hiyori)

内置 Hiyori 高清交互模型，支持全身骨骼动画、动作与物理效果反馈。结合语音交互功能，让您与 AI 智能体拥有真实、温馨的本地化交互窗口。

🧠

智能技能与工具商店

脱离杂乱的控制台选项，全新改版为独立的底部滑出式 Skill Market 面板。支持 AI 智能工作流（Workflow Skills）与 MCP 工具端点的全局搜索与管理。

🔌

手机本地硬件控制

深度调用 Termux-API，允许智能体底层掌控手电筒、高频震动、系统剪贴板实时双向同步以及电池温度与电量健康检查。

Architecture

独立的 Android APK 整合设计

打包在 Termux 里的独立 App

我们对开源的 termux-app 底层 Java 进行了深度改造，将其与 AGI 控制中心进行完美整合：

  • 1
    本地免联网全量解压 工程的 Assets 目录中已全量内置 3.2MB 的 AGI 核心代码与 Live2D 模型包。安装 APK 后，首启时本地自动解压到手机根目录，无网络也能开箱即用。
  • 2
    自动国内源配置与优化 考虑到国内用户访问慢、易失败，首启脚本将非交互地一键把软件包管理器更换为清华大学 apt 镜像源与 清华 PyPI 镜像源，安装速度提升百倍。
  • 3
    双 Tmux 静默后台守护 在手机后台静默拉起 Python 主服务器（port 8085）与基于 SpeechRecognition 的语音唤醒服务进程，随时听候您的唤醒指令。

📱 独立 Android APK 运行壳

Native JVM + 全屏嵌入式 WebView
⬇️ WebView 自动载入 localhost:8085

⚙️ 后台 Termux 终端引擎

自动释放 micro-agi-mvp 运行代码与模型
⬇️ Tmux 静默并发拉起服务

🚀 Python API 核心服务器 & 语音唤醒守护进程

执行本地 AGI 任务、控制系统硬件、读取技能
