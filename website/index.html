Specifications

模块化系统设计

Live2D 交互界面

前端集成 Live2D Cubism SDK，利用 WebGL 渲染本地 Hiyori 模型。支持物理效果反馈、表情切换及平滑的动作衔接，为本地 AGI 提供直观的可视化实体化交互。

解耦式扩展商店

独立的底部抽屉式（Drawer）扩展管理面板。实现 AI 智能工作流（Workflow Skills）与标准 MCP 协议端点（Model Context Protocol）的模块化配置与运行时加载。

系统硬件级控制

基于 Termux-API 实现与系统硬件的深度绑定。智能体可直接控制手电筒开关、震动马达反馈、读取电量温度状态，并实现手机剪贴板的实时双向读写同步。

Under the Hood

安卓端混合编译架构

APK 内部封装与初始化机制

项目通过对官方 termux-app 的原生 Java 代码进行改造，实现应用层与终端后台的透明集成：

  • 1
    免部署内置资源释放 打包时，AGI 源码及模型文件会被压缩为 micro-agi-mvp.zip 存放在 App 的 Assets 目录中。首启时由 Java 自动解压至终端运行目录，无需手动拉取。
  • 2
    自动化国内镜像重定向 针对中国用户自动将默认包管理器仓库源（APT）以及 Python Pip 源重定向至清华大学（Tsinghua）镜像站，实现离线依赖安装加速。
  • 3
    多 Tmux 守护进程并发 Java 启动生命周期中静默拉起 Tmux 服务会话，以多线程并发运行 Python 任务处理服务器与基于 SpeechRecognition 的低功耗语音唤醒进程。
